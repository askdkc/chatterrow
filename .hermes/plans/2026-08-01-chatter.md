# chatter — Discord風チャットグループウェア 実装計画

## 概要
`~/Sites/chatter` に Laravel Svelte Starter Kit + askdkc/breezejp ベースで新規構築。
jin の OnlyOffice/ファイルプレビュー/ガント実装を移植し、UI は Discord 風（サーバー/チャンネル/スレッド）に再設計。

## アーキテクチャ（単一階層・Team不要）
- **Server** (= Discord サーバー / 要件の「プロジェクト」): name, description, starts_on, ends_on, created_by + メンバーシップ (server_user)
- **Channel**: server_id, name, description, starts_on, ends_on, created_by ← **チャンネル=タスク化**（開始日・終了期限を持つ）
- **Message**: server_id, channel_id, user_id, parent_id(スレッド), body
- **Todo**: channel_id, title, details, due_on, assignee_id, completed_at, position ← **チャンネル内todo**
- **StoredFile**: server_id, attachable(morph: message/todo), disk, path, original_name, mime_type, size, preview_path, preview_status ← jin から移植

## フェーズ
1. **P1 依存追加**: reverb, php-jwt, html-sanitizer, boost / @file-viewer, echo, pusher-js
2. **P2 DB+モデル**: migrations (servers, channels, messages, todos, stored_files) + モデル/ファクトリ
3. **P3 jin移植**: OnlyOffice Support 群 + StoredFile プレビュー機構 + config/onlyoffice.php
4. **P4 サーバー/チャンネル CRUD + Discord風3カラムUI**
5. **P5 チャット**: 送信/スレッド/Reverb/チャンネル切替
6. **P6 D&D アップロード + 添付表示**
7. **P7 ファイルビューワー**: ポップアップ + JSプレビュー + OnlyOffice
8. **P8 タスク**: チャンネルタスク化UI + todo + 一覧 (サーバー/チャンネル)
9. **P9 カレンダー+ガント** (サーバー/チャンネル)
10. **P10 期限リマインダー** → チャンネル通知
11. **P11 検証**: feature テスト + build + lint + types:check
